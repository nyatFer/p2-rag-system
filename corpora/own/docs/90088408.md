# シップ (Japanese, suffix, Wiktionary)

シップ (Japanese, suffix, Wiktionary)

Etymology 1

Borrowed from English ship.

Noun

シップ • (shippu)

a ship

(especially) a sailing ship, a tall ship

(rare) shipping, the transportation of goods

Usage notes

The shipping sense is more commonly expressed using the term 出荷 (shukka).

Verb

シップする • (shippu suru) transitive suru (stem シップし (shippu shi), past シップした (shippu shita))

(rare) to ship something

Usage notes

More commonly expressed using the verb 出荷する (shukka suru).
