# 尤も (Japanese, conjunction, Wiktionary)

尤も (Japanese, conjunction, Wiktionary)

See also 尤もらしい

Adjective

尤も • (mottomo) -na (adnominal 尤もな (mottomo na), adverbial 尤もに (mottomo ni))

natural, understandable

Synonym: 当然

Adverb

尤も • (mottomo)

for good reason, naturally

Conjunction

尤も • (mottomo)

but; though; although; that said

Noun

尤も • (mottomo)

something quite right, plausible, understandable
