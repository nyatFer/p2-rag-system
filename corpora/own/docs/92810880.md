# ても (Japanese, suffix, Wiktionary)

ても (Japanese, suffix, Wiktionary)

Etymology

From て (-te, conjunctive suffix) + も (mo, “too, also; even”).

Suffix

ても • (-te mo)

a conjunctive suffix that follows a conditional subordinate clause: even if ...

もう行ってもいい?

Mō itte mo ī?

May I go now?

(literally, “Is it okay (even) if I go now?”)

書店に行かなくてもいいの?

Shoten ni ikanakute mo ī no?

Can I not go to the bookstore?

(literally, “Is it okay (even) if I don't go to the bookstore?”)

すみません、このコピー機を借りても大丈夫ですか？

Sumimasen, kono kopīki o karite mo daijōbu desu ka?

Excuse me, would it be alright if I borrowed this copy machine?

Usage notes

Often used in requests.
