# ぐ (Japanese, suffix, Wiktionary)

ぐ (Japanese, suffix, Wiktionary)

Etymology 1

The hiragana character く (ku) with a dakuten (゛).

Syllable

ぐ • (gu)

The hiragana syllable ぐ (gu). Its equivalent in katakana is グ (gu).

Usage notes

Do not confuse it with the voiced kana iteration mark 〲 which is sometimes used in vertical text.
