# ごっこ (Japanese, suffix, Wiktionary)

ごっこ (Japanese, suffix, Wiktionary)

Suffix

ごっこ • (-gokko)

(archaic) alternately, doing the same action in turns

pretend-, make-believe-

狩りごっこ ― kari-gokko ― mock hunting

探偵ごっこをする ― tantei-gokko o suru ― to play detective

Usage notes

The derivational suffix affixes to a noun.
