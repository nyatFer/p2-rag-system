# ずみ (Japanese, suffix, Wiktionary)

ずみ (Japanese, suffix, Wiktionary)

Etymology

From 済み (sumi). The sumi changes to zumi as an instance of rendaku (連濁).

Suffix

ずみ • (-zumi)

done, finished

作業済み。

Sagyō-zumi.

Work is done.

使用済みのテレビ

shiyō-zumi no terebi

second-hand televisions

削除済

sakujo-zumi

deleted

Usage notes

Attaches to nouns and indicates that the process denoted by the noun has finished.
