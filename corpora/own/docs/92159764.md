# どの (Japanese, suffix, Wiktionary)

どの (Japanese, suffix, Wiktionary)

Etymology 1

Adnominal

どの • (dono)

which .. ? (interrogative demonstrative); what .. ? (one out of the available choices)

どの車がいいか？

Dono kuruma ga ii ka?

Which car do you like?

Usage notes

The hiragana spelling (どの) is preferred to the kanji spelling (何の), which is rarely used.
