# ほな (Japanese, conjunction, Wiktionary)

ほな (Japanese, conjunction, Wiktionary)

Etymology

Short for ほんなら (hon nara), corrupted from それなら (sore nara).

Conjunction

ほな • (hona)

(dialectal, chiefly Kansai) then; well then; if so

Interjection

ほな • (hona)

(dialectal, chiefly Kansai, informal) see you, bye

ほなな。 ― Hona na. ― See ya 'round.
