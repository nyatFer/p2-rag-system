# など (Japanese, particle, Wiktionary)

など (Japanese, particle, Wiktionary)

Etymology

Shift from earlier 何と (nanito).

Adverb

など • (nado) (interrogative)

how, in what way

Particle

など • (nado)

等: for example, things like, such as, etc., and so on

納豆や歌舞伎などは日本だけにある。

Nattō ya kabuki nado wa Nihon dake ni aru.

Things like natto and kabuki are only in Japan.

Usage notes

など (nado), when used as a particle, functions as a noun and may be followed by other particles, including の (no).
