# とか (Japanese, particle, Wiktionary)

とか (Japanese, particle, Wiktionary)

Etymology 1

Case-marking particle と (to) plus adverbial particle か (ka)

Particle

とか • (toka)

something like, some kind of; where the situation is unclear

Etymology 2

Parallel marking particle と (to) (used to join two words together in the same way as や (ya)) plus adverbial particle か (ka)

Particle

とか • (toka)

such as, and so on; used when listing something part of a larger group of similar things

or something, used to avoid stating something clearly and add vagueness

Usage notes

This is not a true particle but is a compound of two particles which is used idiomatically.
