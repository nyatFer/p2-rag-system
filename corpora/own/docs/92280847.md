# それでは (Japanese, conjunction, Wiktionary)

それでは (Japanese, conjunction, Wiktionary)

Conjunction

それでは • (sore de wa)

then; if so; in that case

Synonym: それなら (sore nara)

used to broach a subject; right; well

それでは、始めましょう。 ― Sore de wa, hajimemashō. ― Right then, let's begin.

Interjection

それでは • (sore de wa)

a farewell
