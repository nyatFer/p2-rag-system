# なきゃ (Japanese, suffix, Wiktionary)

なきゃ (Japanese, suffix, Wiktionary)

Etymology

Contraction of なければ（ならない） (nakereba (naranai), literally “will not allow (something) to not happen; if (something) doesn't happen it will be bad”).

Suffix

なきゃ • (-nakya) (appended after imperfective form)

(informal) must, have to

もう行かなきゃ。

Mō ikanakya.

I have to go now.

(informal) if one doesn't...

勉強しなきゃ試験に受からない。

Benkyō shinakya shiken ni ukaranai.

If you don’t study, you will fail the exam.
