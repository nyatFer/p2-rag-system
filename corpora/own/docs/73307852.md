# てある (Japanese, suffix, Wiktionary)

てある (Japanese, suffix, Wiktionary)

Etymology

From て (-te) + ある (aru). Doublet of た (-ta).

Suffix

てある • (-te aru) godan (stem てあり (-te ari), past てあった (-te atta))

indicating the passive result state of an action

窓が開けてある

mado ga akete aru

The window was opened (by someone).

compare:

窓を開ける

mado o akeru

to open the window
