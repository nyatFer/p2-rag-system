# ニダ (Japanese, particle, Wiktionary)

ニダ (Japanese, particle, Wiktionary)

Etymology

From Korean -ㅂ니다 (-mnida, polite declarative suffix). Compare Chinese 思密達／思密达 (sīmìdá).

Particle

ニダ • (nida)

(ethnic slur) Stereotypical sentence-final particle used in place of です (desu) or ます (masu) to mock people of Korean descent.

独島は韓国の物ニダ。

Dokuto wa Kankoku no mono nida.

Dokdo is Korea's, mnida.

Usage notes

Unlike Chinese 思密達 / 思密达 (sīmìdá) which could just be used in a humorous sense, ニダ could only be offensive.
