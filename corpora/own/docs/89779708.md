# なくちゃ (Japanese, suffix, Wiktionary)

なくちゃ (Japanese, suffix, Wiktionary)

Etymology

Contraction of なくては（ならない） (nakute wa (naranai)).

Suffix

なくちゃ • (-nakucha) (appended after imperfective form)

(informal) must, have to

もう行かなくちゃ。

Mō ikanakucha.

I have to go now.

(informal) if one doesn't...

勉強しなくちゃ試験に受からない。

Benkyō shinakucha shiken ni ukaranai.

If you don’t study, you will fail the exam.
