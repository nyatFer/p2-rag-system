# なんぞ (Japanese, particle, Wiktionary)

なんぞ (Japanese, particle, Wiktionary)

Etymology

Adverb

なんぞ • (nanzo)
(interrogative)

why, how, in what way

Particle

なんぞ • (nanzo)

for example, things like, such as, etc., and so on

けんかなんぞするものか！

Kenka nanzo suru mono ka!

As if I'd do something like fighting!

Usage notes

なんぞ (nanzo), when used as a particle, functions as a noun and may be followed by other particles, including の (no).

Phrase

なんぞ • (nanzo)

something
