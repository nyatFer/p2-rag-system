# もしかすると (Japanese, conjunction, Wiktionary)

もしかすると (Japanese, conjunction, Wiktionary)

Etymology

From もしか (moshi ka, “perhaps, if”) + すると (suru to, “doing so”).

Conjunction

もしかすると • (moshi ka suru to)

if that is the case, then ...

Usage notes

The use of すると (suru to) suggests a more certain outcome than the more hypothetical したら (shitara).
