# ごと (Japanese, particle, Wiktionary)

ごと (Japanese, particle, Wiktionary)

Etymology 1

Suffix

ごと • (-goto)

(of time) every

3年ごとの検討

sannen-goto no kentō

triennial review (a review that occurs every three years)

三ヶ月ごと

sankagetsu-goto

every three months

Etymology 2

Suffix

ごと • (-goto)

including, up to, entirely

皮ごと食べる

kawa-goto taberu

to eat it whole, including the skin

Etymology 3

Suffixed form of 事 (koto). The koto changes to goto as an instance of rendaku (連濁).

Suffix

ごと • (-goto)

nominalizer for an action

頼まれごと

tanomare-goto

matter that one has been entrusted with
